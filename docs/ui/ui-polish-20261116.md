## Changes

- Refined the existing blue-and-white identity with a navy text palette, quieter backgrounds, readable status colors, consistent radii, spacing and typography.
- Added reusable buttons, labelled/focus-aware fields, notices, loading/error states, page headings and keyboard-aware form layout in `mobile/src/components/UI.tsx`.
- Reworked shared role headers and status pills. Added button accessibility roles and larger controls on the touched screens. Provider tabs now have icons; owner/provider tab bars reserve room for labels and bottom safe-area insets.
- Login: clearer entry screen, inline required-field feedback, show/hide password, autofill hints, and in-place loading/error feedback. The navigation loading gate now applies to initial session checks, preserving form contents after failed sign-in.
- Signup and add vehicle: shared form layout, clearer headings and provider approval guidance. Signup shows missing required fields. Request payloads and role restrictions are unchanged.
- Owner: garage overview, clearer vehicle cards, readable document statuses, QR dialog with larger controls and scrolling, and honest loading/error/retry states. Fixed the reminder banner's nonexistent navigation target to open renewals. Missing regions display “Not set” instead of an assumed city.
- Provider: inspection summary, clear paid/unpaid sections, reusable inspection action, queue refresh on returning to the screen, and useful loading/error states. Completion uses shared fields and button styling while keeping certificate/date validation and requests. Centre and availability screens use consistent spacing and controls.
- Officer: clearer camera permission guidance, settings recovery when permission cannot be requested again, a scrollable scanner, a visible verification state, and a synchronous scan lock. The camera is removed while the scanner is unfocused. GREEN/RED results retain the server's classification and reasons, with clearer labels, icons and guidance. Removed the phone field the response does not supply. Citation form styling changed; penalty computation and submission payload did not.
- Removed unused styles and imports in touched UI files.
