Install on Android

  1. Scan the QR, or open the link, on the Android phone. Use mobile data if the Wi-Fi blocks large downloads.
  2. Open the downloaded file. If Android asks, allow your browser or Files app to install unknown apps.
  3. This test build is not from the Play Store. Verify the download source and checksum before confirming installation.
  4. Open DriveDock. A yellow "student pilot · test build" strip at the top confirms you have the right app.
  5. Sign in with the account the presenter gives you. Allow camera access to scan QR codes and location access to find stations.

What you can try

  • A vehicle passport with five documents
  • An officer scan that returns GREEN or RED
  • Booking a PUC renewal with a test payment
  • A station certifying the booking
  • Vehicle Twin history and ownership transfer

Known limits

  • The station map uses free OpenStreetMap tiles.
  • No push reminders in this build.
  • Hosted in the cloud (Render + MongoDB Atlas, free tiers); a monitor keeps it awake.
  • Stations, owners and plates are generated sample data.
